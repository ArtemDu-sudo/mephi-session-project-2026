## Примечания

- При первой попытке смонтировать раздел `/mephi-web` возникла ошибка `wrong fs type, bad option, bad superblock` — причина оказалась в опечатке в записи `/etc/fstab` (`defau:ts` вместо `defaults`), из-за которой в файле оказалось две конфликтующие строки для одной точки монтирования. Исправлено удалением некорректной строки.
- Второй диск для `/mephi-web` изначально отсутствовал в `lsblk` — добавлен через настройки виртуальной машины (VirtualBox → Настройки → Носители), так как из гостевой ОС новый диск создать нельзя.
- При настройке `nginx` изменялась директива `root` в `/etc/nginx/nginx.conf` с `/usr/share/nginx/html` на `/mephi-web`; после правки конфиг проверялся `nginx -t` и применялся через `systemctl reload nginx`.
- Файл shadow содержит обезличенные данные: хэши паролей заменены на ***, в целях безопасности.
